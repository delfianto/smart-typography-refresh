# Smart Typography — test vault

Open this vault in Obsidian after running `bun run dev` to try the plugin live.
Type the left-hand sequences in edit mode; they should become the right-hand glyphs:

- `"quoted"` → curly double quotes
- `'quoted'` → curly single quotes
- `...` → ellipsis (…)
- `--` → en dash (–), then another `-` → em dash (—)
- `->` → right arrow (→), `<-` → left arrow (←)
- `<<` / `>>` → guillemets (« »)
- `>=` / `<=` / `/=` → ≥ ≤ ≠
- `1/2` → ½ (enable Fractions in settings)

Press Backspace immediately after a replacement to revert it to what you typed.
